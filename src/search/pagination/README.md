# Pagination.jsx

Numbered pagination display.

### Requirements:

**Base**
* [_config](https://github.com/athoscommerce/snapfu-scaffold-preact-implementations/tree/production/src/_config)

### Import _(path may need to change)_:
```javascript
import { Pagination } from './search/pagination/Pagination';
```

### Component:
```javascript
<Pagination showPrevNextIcon={true} showPrevNextLabel={false} />
```

### Props:
| Prop | Description | Values |
| --- | --- | --- |
| `showPrevNextIcon` | Determines if the previous or next icon should show. _Optional._ | `true`, `false` |
| `showPrevNextLabel` | Determines if the previous or next label should show. _Optional._ | `true`, `false` |
